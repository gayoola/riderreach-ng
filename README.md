# RiderReach NG

Coverage-first Nigerian dispatch discovery prototype.

## Project structure

```text
riderreach-ng/
├── index.html
├── tailwind.config.js
├── css/
│   └── styles.css
├── js/
│   └── app.js
└── README.md
```

## Preview locally

### Easiest
Double-click `index.html` and open it in Chrome or Edge.

### Recommended developer preview
Use VS Code + Live Server:
1. Open the `riderreach-ng` folder.
2. Right-click `index.html`.
3. Choose **Open with Live Server**.

Or use Python:

```bash
python -m http.server 5500
```

Then open `http://localhost:5500`.

## GitHub Pages

Upload the contents of this folder to your GitHub repository.

Then:

**Settings → Pages → Build and deployment → Deploy from a branch → main → / (root) → Save**

## Prototype transparency

The rider profiles, ratings, delivery counts and price bands are simulated demo data.
They are not live rider listings.

The prototype demonstrates destination-based rider discovery and a WhatsApp handoff.
