# RiderReach NG

Presentation-ready prototype for destination-based rider discovery.

## Structure

- `index.html` — page structure
- `css/styles.css` — custom CSS
- `js/app.js` — application logic and prototype data
- `tailwind.config.js` — Tailwind theme extensions
- `README.md` — deployment notes

## GitHub Pages

1. Create a GitHub repository.
2. Upload these files/folders to the repository root.
3. Go to Settings → Pages.
4. Choose Deploy from a branch → `main` → `/ (root)`.
5. Save and open the GitHub Pages URL.

Tailwind is loaded from the CDN in this prototype, so no npm/build process is required.

The rider profiles, ratings, delivery counts and price bands are simulated prototype data.
